# ZEMLIBOGA — Земли Бога

Стратегия в реальном времени для игры с друзьями.

**Как начать:** скачайте [ZEMLIBOGA.exe](https://github.com/NZKT406/ZEMLIBOGA/raw/main/ZEMLIBOGA.exe) и запустите его. Лаунчер сам скачает игру (около 40 МБ, один раз),
дальше — только обновления. Игра хранится в скрытой папке `%LOCALAPPDATA%\ZEMLIBOGA` — рядом с лаунчером ничего лишнего.

Если Windows скажет «Windows защитил ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

Остальные файлы здесь лаунчер берёт сам — скачивать их не нужно.
